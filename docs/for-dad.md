# Dad's Library — the whole guide, one page

## To set it up (someone does this once)

1. Double-click **MoonlightOilSetup.exe**.
2. If Windows asks "Do you want to allow this app to make changes?" click **Yes**.
3. Leave **Docker Desktop (recommended)** selected. Click **Next**, then **Install**.
4. Wait. It downloads a few things — this can take several minutes. That's fine.
5. When it finishes, **restart the computer** (just this once).

## To read (every day)

- Double-click the **📚 Dad's Library** icon on the desktop.
- A window appears that says *"Getting your books ready…"*. Wait a moment.
- Your library opens in the web browser with two big buttons:
  - **🎧 Read & Listen Together** — your books with the audiobook read aloud in sync.
  - **🌊 Focus Reader** — a calm way to read one word at a time.
- You can close the little black window once the library has opened.

## If something looks wrong

- **Blank page?** Wait 30 seconds and refresh (press F5), or close and click the
  icon again.
- **Still stuck?** Restart the computer, then double-click the icon again.
- That fixes almost everything.

## Good to know

- Everything runs **on this computer**. Nothing is online, nothing to log into.
- Your books stay safe even if the app is reinstalled. They live in a folder
  called `C:\Users\Public\MoonlightOil`.
- The first time you open the library it builds itself, so it's slow *once*.
  After that it's quick.
