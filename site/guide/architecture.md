# Architecture

Moonlight Oil has two layers: an **installer** that runs once, and a **container stack** that runs every day.

## Services

### Home Page (`home`)

A static HTML page served by [Caddy](https://caddyserver.com/). Two large cards link to the other services. Features:

- Time-of-day greeting
- Light/dark theme toggle (persisted in localStorage)
- Dynamic hostname detection (works over LAN, not just localhost)
- Help dialog for first-time users
- High-contrast, large text for accessibility

### Storyteller (`storyteller`)

The [official self-hosted image](https://storyteller-platform.dev/docs/installation/self-hosting/) from `registry.gitlab.com/storyteller-platform/storyteller:latest`. Syncs ebook text with audiobook narration so you can read and listen simultaneously.

- Requires `STORYTELLER_SECRET_KEY` (generated by the installer)
- Data persists in `stack/data/storyteller`
- Exposes ports 8001 (web app) and 8002 (Readium engine)

### FlowState Reader (`flowstate`)

Built from source via a [multi-stage Dockerfile](/self-hosting/running-the-stack#why-flowstate-is-built-from-source). The upstream project only publishes to GitHub Pages — there is no official container.

- Node 16 build stage (react-scripts 3.1.1 / webpack 4)
- nginx serve stage with SPA fallback
- Frontend-only, no persistent data

## Installer Scripts

| Script | Purpose |
|--------|---------|
| `common.ps1` | Shared helpers: logging, runtime detection, compose wrapper |
| `install.ps1` | First-time WSL2 + Docker/Podman setup, secret generation |
| `launch.ps1` | Desktop shortcut target: engine start, compose up, browser open |
| `stop.ps1` | Graceful container stop (books are kept) |
| `uninstall.ps1` | Container removal (books and settings are kept) |

## Runtime Detection

The scripts auto-detect which container runtime is installed and use the appropriate compose command:

1. `docker compose` (Docker Desktop with built-in Compose V2)
2. `podman compose` (newer Podman with compose plugin)
3. `podman-compose` (legacy standalone tool)
